# Unity 2D Platformer

This repository contains a Unity 2D Platformer project. It includes features for handling advanced player mechanics and interactions within the game world.

## Key Features

*   **Player Movement:** A robust player movement system allowing for complex platforming maneuvers.
*   **Dash Mechanics:** Includes visual enhancements like dash silhouettes for improved game feel.
*   **Interactables:** Various in-game items, including dash orbs for movement chaining and spikes as environmental hazards.
*   **Save/Load System:** A simple game manager that saves and loads the player's position using `PlayerPrefs`.

## Scripts

Important scripts in this project include:
*   `PlayerMovement.cs`: Handles core player movement, jumping, dashing, and ground/wall checks.
*   `GameManager.cs`: Provides static methods to save and load game state, like player position.
